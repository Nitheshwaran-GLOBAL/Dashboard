HOW TO UPLOAD TO A NEW GITHUB PAGES LINK
-----------------------------------------
1. Create a new GitHub repository, for example: portfolio-2026
2. Upload index.html, style.css, script.js and the complete assets folder.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
4. Wait for GitHub Pages to publish.
5. Your new site will normally be:
   https://YOUR-GITHUB-USERNAME.github.io/portfolio-2026/
